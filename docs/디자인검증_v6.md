# v6 디자인 적용 및 UX 검증

기준일: 2026-10-06. 사용자 승인 v6 흑백 시안을 Flutter 공통 테마와 S1~S10 화면에 적용했다.
디자인·흐름의 기준은 [화면 흐름](02_화면흐름.md#4-공통-규칙)에 둔다.

## 적용 범위

- 흑백 테마, 얇은 구분선, 작은 모서리, 여백으로 화면을 통일했다. Noto Sans KR 가변 폰트를 앱에 포함해 네트워크 없이 Regular·Medium·Semibold를 표시한다.
- 요약 제목과 본문을 분리하고 기존 서버 용어와 정확히 일치하는 부분만 강조한다. 원리·비교·주의 항목에는 기억할 핵심 영역을 사용한다. 시안의 예제 문장이나 정답을 앱 데이터로 넣지 않는다.
- 실제 채점 점수를 표시하고 결과에 따른 격려 문구를 제공한다. 오답은 먼저 펼쳐 선택한 답·정답·해설을 확인하고 다시 풀도록 구성한다.
- 촬영·텍스트 확인·요약·퀴즈의 다음 행동을 하단 안전 영역에 배치했다. 글자 확대 시 본문을 스크롤하고 사진 선택 행동을 세로로 전환한다.

## UX 검토 결과

| 확인한 문제 | 반영한 동작 |
|---|---|
| 책이 미지정인데 요약 버튼을 누르면 책 선택으로 이동함 | 버튼을 책 선택하기로 표시해 다음 화면을 예고 |
| 편집 전 원문이 수정 영역보다 먼저 보임 | 편집 영역을 먼저 표시하고 원문은 아래 접이식으로 제공 |
| 요약·결과 직접 진입 시 이전 화면이 없음 | 상위 회차 목록 또는 요약으로 돌아가는 명시적 버튼 제공 |
| 재응시 때 결과 화면이 계속 쌓일 수 있음 | 퀴즈와 결과 화면을 교체해 요약으로 복귀 |
| 제출 오류로 풀이를 잃을 수 있음 | 답을 유지하고 재제출, 채점 중 중복 제출·이탈 차단 |
| 생성 중 회차를 같은 책의 임의 작업에 연결함 | 홈의 진행 중인 작업 목록으로 안내하고 보관된 jobId로 작업 선택 |
| 큰 글자에서 사진 선택 화면이 넘침 | 전체 본문 스크롤과 행동 줄바꿈 적용 |
| 다크 모드 버튼·아이콘 대비가 부족함 | 모드별 전경색과 색 없는 버튼 글꼴 스타일로 수정 |

## 검증

- `dart format` 및 `flutter analyze`: 통과.
- `flutter test`: 33개 통과. OCR 경계·실패·취소, 작업 복구, 저장 재시도, 인증 재시도, 채점 실패 후 답 보존, 재응시 복귀, 편집 유지, 생성 중 작업 안내를 검증했다.
- 320×640 화면·글자 200%에서 주요 콘텐츠 화면의 레이아웃 예외가 없음을 위젯 테스트로 확인했다.
- Pixel 8 / Android 16(API 36)에서 `integration_test`를 실행해 실제 Flutter 화면 18장을 캡처했다. S1~S10, 다크 모드, 빈 목록·오류, 글자 200%를 포함한다.
- [실제 앱 화면 갤러리](../design/verification/v6/index.html)와 [승인된 v6 시안](../design/concepts/2026-10-06-v6/index.html)을 비교해 가독성, 구분선·버튼 대비, 본문 잘림과 안전 영역을 확인했다.

화면 검증은 가짜 repository 응답을 사용한다. Firebase·운영 서버·실제 LLM 요청을 수행하지 않는다.
OCR 진행은 지연된 가짜 응답, 텍스트 확인은 해당 응답으로 생성된 결과를 사용한다. 실제 사진 선택·ML Kit 정확도·네이티브 권한 다이얼로그 검증과 구분한다.

재현 명령:

```sh
flutter test
flutter drive --driver=test_driver/design_driver.dart \
  --target=integration_test/design_preview_test.dart -d emulator-5554
```

## 남은 확인 사항

- 현재 문서 API 계약에는 과거 응시 결과 조회가 없다. 최근 점수는 서버 응답으로 표시하되 결과 해설 재열기는 이번 앱 실행에서 채점한 결과만 제공한다. 앱 재실행 후 결과 재조회는 서버·앱 계약 보완이 필요하다.
- 생성 중 회차의 documentId↔jobId 연결은 계약 보완이 필요하다. 홈의 작업 목록에서 복구하는 경로는 유지한다.
- 카메라·사진 권한 거절 안내는 적용했다. 기기 설정을 직접 여는 액션과 Android·iOS 실기기의 거절·허용 후 복귀 검증은 남아 있다.
- 실제 카메라·갤러리, 한글 키보드, OCR 정확도, 네트워크 차단·복구, 운영 서버 연동은 [최종 통합 검증 계획](01_기획.md)의 실기기·서버 검증 항목으로 유지한다.
