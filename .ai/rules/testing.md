# 테스트 규칙

전 구간을 덮지 않는다. 규칙이 있고 회귀가 발생하기 쉬운 지점에만 붙인다.

| 대상 | 이유 |
|---|---|
| OCR 실패 판정 | 100자 경계 조건 |
| 촬영·텍스트 입력 제한 | 8장 초과 차단, 페이지 순서 병합, 10,000자 초과분 절단 |
| 인증 실패·재시도 | 로그인·토큰 발급 실패 후 재시도에서 인증이 다시 실행되는지 확인 |
| 네트워크 실패·복구 | 요청 실패·타임아웃·오프라인 후 안내와 재시도 동작 확인 |
| 비동기 작업 복구 | 폴링 중 연결 단절·실패·화면 이탈 후 재진입 경로 확인 |

외부 인증·네트워크 호출은 가짜 응답으로 대체하고, 실패 후 재시도에서 실제
실패 원인이 다시 실행되는지 확인한다.
