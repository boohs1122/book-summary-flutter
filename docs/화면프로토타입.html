원문 프로세스는 실행 중인 프로그램을 의미한다. 프로그램이 저장 장치에 담긴 정적인 코드라면, 프로세스는 메모리에 적재되어 CPU를 할당받는 동적인 실행 단위다.

운영체제는 프로세스를 다섯 가지 상태로 관리한다. 생성 상태에서 시작해 준비 상태로 진입하고, 스케줄러가 CPU를 할당하면 실행 상태가 된다. 입출력 요청이 발생하면 대기 상태로 전환되며, 작업이 끝나면 종료 상태로 이동한다.

각 프로세스의 상태 정보는 PCB(Process Control Block)라는 자료구조에 저장된다. PCB에는 프로세스 식별자, 프로그램 카운터, 레지스터 값, 메모리 관리 정보가 담긴다. 문맥 교환이 일어날 때 운영체제는 현재 프로세스의 PCB에 상태를 저장하고…

프로세스 관리

정의

프로세스의 정의

실행 중인 프로그램. 저장 장치의 정적인 코드와 달리 메모리에 적재되어 CPU를 할당받는 동적 단위다.

원리

상태 전이 과정

생성에서 시작해 준비·실행·대기를 오가며 종료로 향한다. 전이는 스케줄러가 관리한다.

원인

문맥 교환이 필요한 이유

CPU는 하나인데 실행할 프로세스는 여럿이라 번갈아 처리해야 하며, 그 과정에서 오버헤드가 발생한다.

예시

워드프로세서의 경우

실행하면 프로세스가 생성되고, 저장 중에는 입출력을 기다리며 대기 상태가 된다.

비교

프로세스와 스레드

프로세스는 독립된 메모리를 갖고, 스레드는 같은 프로세스 안에서 메모리를 공유한다.

주의

준비와 대기는 다르다

준비는 CPU 할당을 기다리는 상태, 대기는 입출력 완료를 기다리는 상태다. 혼동하기 쉽다.
